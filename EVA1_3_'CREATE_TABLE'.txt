Relación -> Se ve como una tabla de valores
	    Contiene un conjunto de filas
	     -> Cada fila tiene elementos que representan a una entidad real
	       -> En el modelo formal, las filas se llaman tuplas
             -> Cada columna tiene un encabezado que representa sus items
	       -> En el modelo formal, el encabezado se llama atributo

Key (Llave) -> Valor que identifica únicamente a una fila en la tabla
Llave artificial -> (…)

NORMALIZACION Y FORMAS NORMALES

Reducen la cantidad de información en una bdd eliminando datos redundantes.

1st -> ATOMICIDAD: Valor que no puede ser dividido en piezas más pequeñas
	En una tabla en 1FN todos los valores son atómicos y funcionalmente tienen que depender en una llave primaria, sin contener grupos repetidos (datos duplicados en la misma columna).

2nd -> REMOVER DEPENDENCIAS PARCIALES.
	-> Registros no deben de depender en algo que no sea la llave primaria.
	-> Crea tablas separadas por cada conjunto de datos relacionados > Identificar cada dato con su propia llave primaria > Es necesario introducir una nueva relación entre las tablas > se crean llaves foráneas.
	-> Integridad referencial: cada valor de una llave foránea debe existir como llave primaria en otra tabla

3rd -> REMOVER DEPENDENCIAS TRANSITIVAS (IF A>B, AND B>C, THEN A>C)
	-> Cada atributo no debe depender de otro atributo no primario, cada atributo debe representar a la llave
